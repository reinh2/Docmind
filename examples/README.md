# Standalone widget demo

`demo-site.html` is a static page for a fictional client ("Berlin Law
Partners") with the DocMind widget embedded, exactly as a real customer site
would embed it — one `<script>` tag, nothing else.

Run `make up` to start the API and admin console, then `make demo-site` to
serve this page and `make open` to open both in your browser. See `make help`
for the full list of commands.
